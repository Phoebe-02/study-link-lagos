# Study Link Lagos

**Track:** Frontend Development
**Stack:** HTML, CSS, JavaScript (no frameworks in Week 1)

**Target user:** University students in Lagos who need a quiet, affordable place to study with power and Wi-Fi.

**Problem:** Students waste time and money hunting for study spaces. They cannot quickly see which places are quiet, cost how much, or have power and Wi-Fi.

**Core flow:** Browse list of study spots -> search and filter -> save favourites

**Data source:** Mock data (sample spots stored in `script.js`). A JSON file or public API may follow in Week 2.

**In scope:**
- Responsive list of study spot cards
- Search by name
- Save / unsave a spot
- Area and amenity filters
- Accessible, mobile-first layout

**Out of scope:**
- User accounts and logins
- Payments or bookings
- Real-time availability
- User reviews
- Maps

**Top 3 risks:**
1. Running out of time on layout and polish, since I am a beginner in frontend.
2. Filter logic getting messy when search, area and amenities are combined.
3. Accessibility details (contrast, keyboard use, focus) being skipped.
